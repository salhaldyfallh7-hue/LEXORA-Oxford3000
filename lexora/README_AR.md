# LEXORA — منصة تعلّم المفردات

منصة عربية RTL لتعلّم المفردات الإنجليزية بمراحل A1 وA2 وB1 وB2، مع لوحة متابعة، مكتبة كلمات، اختبارات متنوعة، أخطاء ومراجعة متباعدة، مفضلة، إحصائيات، مظهر ليلي/نهاري، ونسخ احتياطي محلي.

## حالة التسليم

- تم تطوير الواجهة والوظائف الأساسية بالاعتماد على صفحة `index.html` التي أرسلتها، مع إعادة تنظيمها إلى ملفات قابلة للصيانة.
- لا تحتوي الحزمة على قائمة Oxford 3000 الكاملة أو نسخة من ملف PDF. قائمة Oxford منشور محمي بحقوق نشر؛ لذلك تُرك ملف `data/oxford3000.json` فارغًا بدل إعادة نشر القائمة داخل هذه الحزمة.
- يجب إضافة ملف بيانات JSON تملك حق استخدامه، ثم التحقق منه. مخطط البيانات موجود في `data/schema.json` وأداة التحقق في `scripts/validate_database.py`.
- لا توجد قاعدة ترجمة عربية مكتملة مضمونة ضمن الملفات الحالية. لا تُعرض كلمات وهمية أو أمثلة مختلقة لتعويض النقص.
- تقرير التدقيق `reports/source-audit.json` يوثق إحصاءات ملف Oxford الذي أرسلته فقط، ولا يحتوي القائمة نفسها.

## تجهيز قاعدة الكلمات

ضع قاعدة البيانات المصرّح لك باستخدامها في:

`data/oxford3000.json`

ثم شغّل في PowerShell أو CMD من مجلد المشروع:

```bash
python scripts/validate_database.py --file data/oxford3000.json
```

تتطلب كل مفردة `id` و`headword` و`forms` و`levels` و`meanings`. لكل تصنيف لغوي في `forms` يجب حفظ `partOfSpeech` و`level`. يسمح بـ `null` للمستوى فقط عندما لا يحدده المصدر. القيم المقبولة للمستويات هي A1 وA2 وB1 وB2؛ لا يوجد C1 في هذا الإصدار.

مثال بنيوي مختصر غير مرتبط بقائمة Oxford:

```json
{
  "schemaVersion": 1,
  "dataset": "Your authorized vocabulary dataset",
  "words": [
    {
      "id": "your-id-001",
      "headword": "YOUR_WORD",
      "searchHeadword": "your_word",
      "forms": [{ "partOfSpeech": "n.", "level": "A1" }],
      "levels": ["A1"],
      "meanings": ["أدخل المعنى الموثوق هنا"],
      "translationStatus": "reviewed",
      "exampleEnglish": null,
      "exampleArabic": null
    }
  ]
}
```

## التشغيل على الكمبيوتر

1. ثبّت Python 3 إذا لم يكن موجودًا.
2. بعد إضافة قاعدة البيانات والتحقق منها، انقر مرتين على `run_local.bat`.
3. ستفتح المنصة على `http://localhost:8000`.
4. لا تفتح `index.html` بالنقر المزدوج؛ استخدم الخادم المحلي حتى تعمل وحدات JavaScript وIndexedDB وService Worker بصورة صحيحة.

أو شغّل يدويًا:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## التثبيت كتطبيق PWA

- على الكمبيوتر: افتح النسخة المستضافة عبر HTTPS أو `localhost` في متصفح يدعم PWA، ثم استخدم أمر التثبيت في شريط العنوان أو زر التثبيت داخل المنصة عند ظهوره.
- على Android: ارفع المجلد إلى استضافة HTTPS، افتح رابط الموقع في Chrome، ثم اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- يجب فتح الموقع مرة أولى مع اتصال حتى يخزّن Service Worker ملفات التطبيق وقاعدة البيانات. بعد ذلك جرّب العمل دون اتصال.
- `localhost` على الكمبيوتر لا يعني `localhost` على الهاتف؛ لتثبيت الهاتف استخدم رابط HTTPS يمكن للهاتف الوصول إليه.

## العمل دون اتصال والصوت

ملفات التطبيق الأساسية تُخزّن بواسطة Service Worker، أما تقدم المستخدم والمفضلة والاختبارات فتُخزن في IndexedDB داخل المتصفح. لا توجد حاجة لاتصال إنترنت بعد التخزين الأولي للملفات والبيانات.

لا تتضمن الحزمة ملفات صوتية خارجية. تُعرض أزرار النطق فقط عندما يبلّغ المتصفح عن صوت نظام محلي للغة المطلوبة (`localService`). لا يوجد ضمان بأن كل جهاز يحتوي صوتًا محليًا عربيًا أو إنجليزيًا؛ لم يتم اختبار أصوات جهازك الفعلية.

## البيانات والنسخ الاحتياطي

من «الإعدادات والنسخ الاحتياطي» اختر «تصدير نسخة احتياطية» لحفظ التقدم والمفضلة والأخطاء والمستويات المفتوحة وسجل الاختبارات في ملف JSON. للاستعادة، اختر «استعادة البيانات» وحدد الملف السابق. الاستيراد يستبدل بيانات التقدم الحالية.

بيانات IndexedDB مرتبطة بعنوان الموقع والمتصفح والجهاز. لا تمسح بيانات الموقع أو المتصفح قبل تصدير نسخة احتياطية. تغيير نطاق الاستضافة أو عنوانها قد يجعل المتصفح يعامل الموقع كأصل جديد.

## آلية فتح المستويات

- يبدأ الحساب بالمستوى A1.
- الاختبار النهائي يفتح المستوى التالي عند `scorePercentage >= 90`.
- 89% لا يفتح المستوى التالي؛ 90% و91% و95% و100% تنجح.
- يظل المستوى الذي سبق فتحه مفتوحًا، ولا يُعاد طلب اختبار لفتحه.
- لا يُنشأ مستوى C1.

## الاختبارات التي أُجريت

راجع `TEST_REPORT_AR.md`. اختبارات JavaScript ومنطق الانتقال البرمجي نجحت. تعذّر إجراء اختبار واجهة متصفح كامل في بيئة البناء لأن سياسة البيئة منعت فتح عناوين localhost (`ERR_BLOCKED_BY_ADMINISTRATOR`). لذلك لم يتم الادعاء بأن التثبيت على هاتف فعلي أو العمل Offline على جهاز المستخدم قد اختُبر.

## تشغيل الاختبارات البرمجية

على Windows، بعد تثبيت Node.js:

```bat
run_tests.bat
```

أو شغّل `node tests/core.test.mjs` و`node tests/db.test.mjs` يدويًا. اختبار قاعدة البيانات في الحزمة يستخدم محاكاة لاختبار استدعاءات طبقة البيانات والنسخ الاحتياطي، ولا يغني عن اختبار IndexedDB الأصلي في المتصفح.
